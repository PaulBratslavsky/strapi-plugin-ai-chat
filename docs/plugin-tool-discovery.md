# Plugin Tool Discovery — moved

This was an RFC proposing cross-plugin tool discovery. The proposal shipped, so
it is no longer a plan and no longer describes anything not already built.

**Current reference:** [plugin-contract.md](./plugin-contract.md) — the
`ai-tools` service, `ToolDefinition`, Zod rules, namespacing, permissions, and
how to build an extension plugin.

**For how discovery works internally:**
[architecture.md](./architecture.md#plugin-tool-discovery).

The original document is preserved unchanged at
[`old/plugin-tool-discovery.md`](./old/plugin-tool-discovery.md), including the
phased implementation plan and the survey of the three plugins that motivated
it.
